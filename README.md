## About

I work across **offensive security**, covering application and API security, identity, enterprise infrastructure, cloud environments and human-focused attack vectors.

My work is not tied to a single technology, platform or attack surface. I approach security assessments from an adversarial perspective and focus on understanding how systems, identities, applications and people interact within the broader environment.

My work includes **penetration testing, red teaming, black teaming, adversary simulation, social engineering and security research**.
